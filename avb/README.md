# avb

`avbtool.py` is vendored unmodified from AOSP `platform/external/avb` (branch `main`, commit `761178607206f4cb2af79ed9eec52d8cbd814adb`, avbtool 1.3.0) under its MIT licence (`LICENSE`, copied from the same commit). It is used only by `scripts/sign-boot-avb.sh` to add the signed AVB hash footer that stock ABL requires on `boot_b`.
